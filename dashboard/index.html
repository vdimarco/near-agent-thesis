2. Reproducible Charts and Underlying Queries

What Chart 1 shows: Gasless DELEGATE_ACTION receipts make up 65.0% of sampled mainnet actions and sub-accounts appear in 35.4% of transactions, while scoped FunctionCall keys represent 18.9% of active keys across inspected accounts (with intents.near using 9 FunctionCall keys and 0 FullAccess keys).

View SQL & RPC Query Behind Chart 1 (sql/01_agent_primitives_daily.sql + FastNEAR view_access_key_list) 
SELECT
  ra.block_date,
  ra.action_kind,
  COUNT(1) AS action_count,
  COUNT(DISTINCT ra.receipt_predecessor_account_id) AS unique_predecessors,
  COUNT(DISTINCT ra.receipt_receiver_account_id) AS unique_receivers,
  COUNTIF(
    ra.action_kind = 'ADD_KEY'
    AND JSON_EXTRACT_SCALAR(ra.args, '$.access_key.permission.permission_kind') = 'FUNCTION_CALL'
  ) AS scoped_function_call_keys,
  COUNTIF(
    ra.action_kind = 'ADD_KEY'
    AND JSON_EXTRACT_SCALAR(ra.args, '$.access_key.permission.permission_kind') = 'FULL_ACCESS'
  ) AS full_access_keys
FROM `bigquery-public-data.crypto_near_mainnet_us.receipt_actions` AS ra
WHERE ra.block_date BETWEEN DATE('2025-09-01') AND DATE('2026-03-24')
  AND ra.action_kind IN ('FUNCTION_CALL', 'DELEGATE_ACTION', 'ADD_KEY', 'CREATE_ACCOUNT')
GROUP BY ra.block_date, ra.action_kind
ORDER BY ra.block_date ASC, action_count DESC;

View SQL Query Behind Chart 2 (sql/02_receiver_concentration.sql) 
SELECT
  ra.block_date,
  ra.action_kind,
  ra.receipt_receiver_account_id AS receiver_account_id,
  COUNT(1) AS receipt_count,
  COUNT(DISTINCT ra.receipt_predecessor_account_id) AS unique_callers
FROM `bigquery-public-data.crypto_near_mainnet_us.receipt_actions` AS ra
WHERE ra.block_date BETWEEN DATE('2026-01-01') AND DATE('2026-03-24')
  AND ra.action_kind IN ('DELEGATE_ACTION', 'FUNCTION_CALL')
GROUP BY ra.block_date, ra.action_kind, receiver_account_id
QUALIFY ROW_NUMBER() OVER (
  PARTITION BY ra.block_date, ra.action_kind
  ORDER BY COUNT(1) DESC
) <= 25
ORDER BY ra.block_date ASC, ra.action_kind ASC, receipt_count DESC;

View SQL Query Behind Chart 4 (sql/03_gas_and_storage_costs.sql) 
SELECT
  ra.action_kind,
  COUNT(1) AS sample_receipts,
  APPROX_QUANTILES(eo.gas_burnt, 100)[OFFSET(50)] AS p50_gas_burnt,
  APPROX_QUANTILES(eo.gas_burnt, 100)[OFFSET(95)] AS p95_gas_burnt,
  AVG(SAFE_CAST(eo.tokens_burnt AS FLOAT64) / 1e24) AS mean_near_burnt
FROM `bigquery-public-data.crypto_near_mainnet_us.receipt_actions` AS ra
JOIN `bigquery-public-data.crypto_near_mainnet_us.execution_outcomes` AS eo
  ON ra.receipt_id = eo.receipt_id
  AND ra.block_date = eo.block_date
WHERE ra.block_date BETWEEN DATE('2026-03-01') AND DATE('2026-03-24')
  AND eo.block_date BETWEEN DATE('2026-03-01') AND DATE('2026-03-24')
  AND ra.action_kind IN ('ADD_KEY', 'DELETE_KEY', 'CREATE_ACCOUNT', 'DELEGATE_ACTION', 'FUNCTION_CALL')
GROUP BY ra.action_kind
ORDER BY sample_receipts DESC;

3. Thesis Summary: Evidence For, Evidence Against, and What Changes Our Mind

Evidence For the Thesis

  • Zero-contract scoped keys: Adding or rotating a method-scoped FunctionCall key on NEAR is a native protocol action costing ~$0.00036, avoiding ERC-4337 smart account deployment and session-key validator modules.
  • Tight cross-chain settlement: NEAR Intents 1Click swaps settle across 229 tokens with a 1.67 bps median spread on $100 to $1,000 orders and 13.56 GB of active onchain state in intents.near.
  • Gasless relayer maturity: 65.0% of sampled mainnet actions already execute via NEP-366 DELEGATE_ACTION meta-transactions.

Evidence Against & Falsification

  • Consumer relayer concentration: 66.4% of top-receiver receipts hit just 3 consumer apps (token.sweat, spin.sweat, game.hot.tg).
  • Failed Check 1 (18.9% vs. 25.0%): Consumer relayers use FullAccess key pools rather than scoped FunctionCall keys, pulling the sample key share to 18.9%.
  • Sub-account storage lockup & $1 spread floor: Dedicated sub-accounts lock $6.48 per 100 agents, and $1 cross-chain swaps pay 67.96 bps median spread. Agents should share a parent account via scoped keys and batch cross-chain payouts above $10 (8.78 bps).
